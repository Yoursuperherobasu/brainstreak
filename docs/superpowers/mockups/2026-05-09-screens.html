Notes for the React Native build: Hero gradient is the same primary→primaryDark used elsewhere; the radial decoration behind it should be optional ornament. The streak flame is a recurring metaphor — use 🔥 emoji at varying sizes; the orange glow halo is achievable with shadow color. The sign-in card uses a violet/cyan blended fill to set itself apart from regular cards. Settings rows mirror native iOS settings with toggle on the right. Difficulty selector is segmented across 4 columns, gap 8px. Category grid is 3 columns × 2 rows, square aspect ratio.
